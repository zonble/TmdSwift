# TMD Sample Scores Directory

This directory contains sample TMD (Timebase Mark Down) scores demonstrating syntax capabilities ranging from minimal syntax tests to complex, multi-track orchestral and modern band arrangements.

---

## Directory Structure

### 1. `basic/` (Syntax Basics & Mini Demonstrations)
Lightweight scores ideal for syntax testing, learning basic notation, and single-track or simple lead sheets.

| File | Description | BPM / Key | Features |
|------|-------------|-----------|----------|
| [`tiger.tmd`](basic/tiger.tmd) | 兩隻老虎 (Two Tigers) | 120 / C | Minimal Hello World example; single track, 4/4 meter. |
| [`三天三夜.tmd`](basic/三天三夜.tmd) | 三天三夜 (Three Days Three Nights) | 133 / Bb | Standard lead sheet with chords, drums, and vocal melody. Used across test suites. |
| [`haoqin.tmd`](basic/haoqin.tmd) | 豪情 (Heroic Spirit) | 88 / Dm | Expressive pentatonic melody with basic chord accompaniment. |
| [`orz.tmd`](basic/orz.tmd) | orz (失意體前屈) | 116 / D | Classic online meme tune; fast tempo, pop ballad chord framework. |
